# ترهونة ماركت — تطبيق MVP

هذا مشروع تطبيق Android مبني بـ Expo/React Native، والواجهة الأساسية جاهزة:
- الرئيسية والتصنيفات
- سوق المنتجات
- تفاصيل المنتج
- إضافة إعلان مع صورة
- المطاعم
- التوصيل
- الخدمات
- الحساب
- اتصال بقاعدة بيانات Supabase عند إضافة مفاتيح المشروع

## تشغيله
1. ثبّت Node.js.
2. داخل مجلد المشروع شغّل:
   `npm install`
3. انسخ `.env.example` إلى `.env` وضع بيانات Supabase.
4. شغّل:
   `npx expo start`
5. افتح التطبيق على هاتف Android باستخدام Expo Go أثناء التطوير.

## قاعدة البيانات
نفّذ ملف `supabase/schema.sql` داخل SQL Editor في مشروع Supabase.

## مهم
هذه نسخة MVP قابلة للتطوير، وليست نسخة منشورة على Google Play بعد.
لا تضع مفتاح service_role داخل التطبيق. استخدم فقط anon key مع سياسات RLS.
